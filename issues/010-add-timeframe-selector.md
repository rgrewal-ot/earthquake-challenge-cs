# #10 Add timeframe selector

**Points:** 2-points, frontend

Allow users to choose which time period to view (hour, day, week, month).

**USGS endpoints:**
- `all_hour.geojson`
- `all_day.geojson`
- `all_week.geojson`
- `all_month.geojson`

**Acceptance Criteria:**
- [ ] User can select different timeframes
- [ ] Selecting a timeframe fetches new data
- [ ] UI updates to show the new data
