# #6 Color-code markers by magnitude

**Points:** 2-points, frontend

Make earthquake markers visually indicate severity through color.

**Suggested scale:**
- Green: magnitude < 2.0 (minor)
- Yellow: magnitude 2.0-4.0 (light)
- Orange: magnitude 4.0-6.0 (moderate)
- Red: magnitude ≥ 6.0 (strong/major)

**Acceptance Criteria:**
- [ ] Markers have different colors based on magnitude
- [ ] Color scale is intuitive (more severe = more alarming color)
