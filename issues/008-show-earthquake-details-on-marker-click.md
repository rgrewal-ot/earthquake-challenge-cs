# #8 Show earthquake details on marker click

**Points:** 2-points, frontend

When clicking on an earthquake marker, display its details.

**Should show:**
- Magnitude
- Location (place name)
- Time (human-readable)
- Depth

**Acceptance Criteria:**
- [ ] Clicking a marker shows earthquake details
- [ ] Details are readable and well-formatted
- [ ] Time is displayed in a human-friendly format
