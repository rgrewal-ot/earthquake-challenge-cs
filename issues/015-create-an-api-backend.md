# #15 Create an API backend

**Points:** 3-points, backend

Build a backend API that proxies/processes earthquake data.

**Suggested endpoints:**
- `GET /api/earthquakes` - get earthquake data
- `GET /api/earthquakes/stats` - get statistics

**Acceptance Criteria:**
- [ ] Backend API is functional
- [ ] Returns earthquake data in a usable format
- [ ] Frontend can fetch from this API instead of directly from USGS
