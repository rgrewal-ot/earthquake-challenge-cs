# #2 Fetch earthquake data from USGS API

**Points:** backend, 1-point

Implement a function or service that fetches earthquake data from the USGS GeoJSON feed.

**API Endpoint:** `https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson`

**Acceptance Criteria:**
- [ ] Successfully fetches data from USGS API
- [ ] Handles network errors gracefully
- [ ] Returns parsed JSON data
